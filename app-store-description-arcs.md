# Arcs App Store Copy

## App Store Description (Primary)

`Arcs` helps you cut through the noise so you can quickly spot trends and useful NBA insights.

Designed for everyday fans, `Arcs` turns fast-moving game and player data into clear takeaways you can actually use:
- Real-time game and player insights as things change
- Trend views and hit rates to help you see what is consistent
- Prop simulation and tracking to test ideas and review results
- Simple context around averages and recent performance
- Clear, plain-language explanations instead of heavy stats jargon

Whether you are checking matchups before tipoff or following the action live, `Arcs` helps you understand what matters most—without overcomplicating it.
